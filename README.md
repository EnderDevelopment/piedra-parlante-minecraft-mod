# Piedra Parlante

Piedra Parlante is a Minecraft mod that introduces an interactive entity called 'Piedra Parlante'. Using the Script API, the mod secretly counts how many common stone blocks the player mines. After the player breaks exactly the eighth stone block, the entity appears at that position, performs a jump animation, and displays the text '¡Auch! ¡Auch!' in the chat. It then presents a native form with the message '¿Qué vas a hacer conmigo?' and two selectable buttons: one that triggers an aggressive animation and deals damage to the player, and another that makes the entity peaceful and sets up a timer to scan the map for nearby villages and valuable minerals, displaying their coordinates in the chat every 60 seconds.

## Install

1. Download the mod file from the GitHub repository.
2. Place the downloaded file in the `mods` folder of your Minecraft instance.
3. Launch Minecraft and ensure the mod is loaded correctly.

## Use

1. Start a new Minecraft world or load an existing one.
2. Begin mining common stone blocks.
3. After breaking exactly the eighth stone block, the Piedra Parlante entity will appear at that location.
4. Interact with the entity to trigger the form and choose one of the options.
